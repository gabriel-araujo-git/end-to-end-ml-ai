# end-to-end-ml-ai 🚀

Este repositório demonstra domínio completo em **Machine Learning** e **Inteligência Artificial**, cobrindo desde conceitos fundamentais até aplicações avançadas.  
Cada projeto foi desenvolvido em **Python**, utilizando boas práticas de engenharia, documentação e reprodutibilidade.

---

## 📂 Estrutura do Repositório

tabular_pipeline.py → ML tabular com XGBoost, Optuna e SHAP

image_train.py → Treinamento de imagens com PyTorch (ResNet50)

hf_finetune.py → Fine-tuning de Transformers para NLP

README.md → Este documento

---

## 🚀 Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/end-to-end-ml-ai.git
   cd end-to-end-ml-ai
   ```

2. Crie e ative um ambiente virtual:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   venv\Scripts\activate   # Windows
   ```

3. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```

4. Abra os notebooks no Jupyter ou VSCode:
   ```bash
   jupyter notebook
   ```

## 📦 Dependências

- TensorFlow / PyTorch

